# CocoCat 视觉设计方向

> 确立时间：2026-05-18  
> 方向：**太极双猫** — 一橙一白自然互嵌，纯白背景  
> 隐喻：两只猫 = 两个 agent 协作  
> 风格：纯色块，极简扁平

---

## 形象

- 两只猫自然蜷抱成圆，身体曲线顺势流动
- 一橙 `#f97316` + 一白杏 `#faf5f0`
- S 弧分割线柔和，不是刀切——两只猫像本来就长在一起
- 每只猫：弧线身体 + 三角耳 + 一个圆点眼睛
- 纯色块，无渐变阴影描边
- 背景纯白

---

## 配色

| 色块 | 色值 |
|------|------|
| 橙猫 | `#f97316` |
| 白猫 | `#faf5f0` |
| 眼睛 | `#3b2f2f` |
| 背景 | `#ffffff` |

四个颜色。

---

## 禁止

- ❌ 深色背景 / 暗底圆
- ❌ 渐变 / 阴影 / 描边
- ❌ 两只猫被生硬切开
- ❌ 三只猫 / 一只猫
- ❌ 冷色
