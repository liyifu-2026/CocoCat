# CocoCat 视觉设计方向

> 确立时间：2026-05-18  
> 方向：**太极双猫** — 一橙一白两只猫互相环抱成圆  
> 隐喻：两个 agent 协作 = 太极阴阳  
> 风格：纯色块，极简扁平

---

## 形象

```
  圆形内两只猫：
  ┌──────────┐
  │  🐱橙  🐱│
  │     白   │
  └──────────┘
```

- 橙色猫 + 白色猫，像太极图互相环抱
- 每只猫：一个弧形色块做身体 + 三角耳 + 一个小圆点眼睛
- 纯色块，无渐变阴影描边

---

## 配色

| 色块 | 色值 |
|------|------|
| 橙猫 | `#f97316` |
| 白猫 | `#fafaf5` |
| 背景 | `#3b2f2f` |
| 眼睛 | `#5c3d2e` |

就四个颜色。

---

## 禁止

- ❌ 渐变 / 阴影 / 描边
- ❌ 三只猫 / 只有一只猫
- ❌ 皮毛纹理 / 花纹
- ❌ 冷色
- ❌ 3D / 写实
