## 数据流

```
用户 ──→ 渠道（微信/飞书/API）
         │
         ▼
    web (FastAPI) ──→ py-agent (ReAct Loop)
         │                    │
         │                    ├── LLM 调用
         │                    ├── 工具执行
         │                    └── 记忆读写
         │
         ▼
    src (Rust 核心)
         │
         ├── Agent 生命周期
         ├── 消息路由
         └── 场景调度
```

## 关键说明

- **Rust 核心** (`src/`) 不直接调用 LLM，只负责编排
- **Python 运行时** (`py-agent/`) 是唯一调用 LLM 的模块
- **Agent 数据** (`agents/`) 放在文件系统中，方便检查和手动修改
- **场景** (`scenes/`) 定义了多 Agent 协作的交互流程
- **技能** (`skills/`) 是 Agent 可以加载的独立能力单元
