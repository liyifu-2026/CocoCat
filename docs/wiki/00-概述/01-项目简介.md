# 项目简介

> **受众：** 新用户、技术评估者、开源贡献者  
> **前提：** 无  
> **目标：** 理解 CocoCat 是什么、为什么存在、整体架构

## 什么是 CocoCat？

CocoCat 是一个**多智能体 AI 协作平台**。约 20 个 AI 代理（Agent）以虚拟团队的形式协同工作，各自承担不同的角色（客服、编程、写作、数据分析等），通过统一的消息总线进行通信和协作。

## 核心理念

- **Agent 即角色**：每个 Agent 有独立的身份、记忆、技能和 LLM 配置，像一个虚拟员工
- **场景驱动**：Scene 定义 Agent 之间的交互流程，类似剧本
- **渠道无关**：同一套 Agent 团队可通过微信、飞书、Web API 等渠道与用户交互
- **安全可控**：命令沙箱、文件权限控制、JWT 认证层层防护


## 技术栈

| 层级 | 技术 |
|------|------|
| 核心引擎 | Rust（edition 2021） |
| Agent 运行时 | Python 3.12+（ReAct Loop） |
| Web 后端 | FastAPI |
| Web 前端 | React |
| 数据库 | 文件系统 + JSON |
| LLM 接口 | OpenAI 兼容 API（DeepSeek / GPT 等） |

## 安全机制

- **JWT 认证**：所有 API 请求需携带有效 Token
- **命令沙箱**：Agent 执行命令受白名单和工作目录限制
- **文件访问控制**：Agent 只能访问授权路径
- **网络隔离**（Linux）：可选网络命名空间隔离
