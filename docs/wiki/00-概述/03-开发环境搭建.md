# 开发环境搭建

> **受众：** 开发者、贡献者  
> **前提：** 熟悉命令行操作  
> **目标：** 安装完整的 CocoCat 开发环境

## 必需工具

### Python 3.12+

CocoCat 的 Agent 运行时需要 Python 3.12 或更高版本。

**Windows：**

从 [python.org](https://www.python.org/downloads/) 下载安装包，安装时勾选 "Add Python to PATH"。

验证安装：

```bash
python --version
# 输出: Python 3.12.x
```

### Rust 1.84+（edition 2021）

Rust 核心引擎要求 edition 2021，对应 Rust 1.84 或更高版本。

推荐使用 `rustup` 安装：

```bash
# Windows 用户从 https://rustup.rs 下载安装
rustup-init.exe

# 验证
rustc --version
# 输出: rustc 1.84.x
cargo --version
# 输出: cargo 1.84.x
```

如果现有版本过低，更新：

```bash
rustup update stable
```

### Node.js 20+ 和 npm

Web 管理面板（React）需要 Node.js 20 或更高版本。

**Windows：**

从 [nodejs.org](https://nodejs.org/) 下载 LTS 版本安装包。

验证安装：

```bash
node --version
# 输出: v20.x.x
npm --version
# 输出: 10.x.x
```

## 可选工具

| 工具 | 用途 | 安装方式 |
|------|------|----------|
| Git | 版本控制 | `winget install Git.Git` |
| VS Code | 代码编辑 | `winget install Microsoft.VisualStudioCode` |
| Python venv | 虚拟环境 | 内置 `python -m venv venv` |
| Docker | 容器化部署 | Docker Desktop for Windows |

## 验证完整环境

运行以下命令确认所有工具就绪：

```bash
python --version && rustc --version && node --version
```

全部成功输出后，即可按照[快速开始](02-快速开始.md)启动 CocoCat。
