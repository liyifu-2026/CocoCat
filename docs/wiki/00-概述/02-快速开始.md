# 快速开始

> **受众：** 新用户、开发者  
> **前提：** 已安装 Python 3.12+、Rust 1.84+、Node.js 20+  
> **目标：** 5 分钟内本地启动 CocoCat

## 第一步：克隆仓库

```bash
git clone https://github.com/your-org/cococat.git
cd cococat
```

## 第二步：配置环境变量

复制环境变量模板并填入你的 LLM API Key：

```bash
cp .env.example .env
```

编辑 `.env`，至少修改以下两项：

```ini
OPENAI_API_KEY=sk-your-api-key-here
WEB_PASSWORD=设置一个管理密码
```

## 第三步：安装 Python 依赖

需要安装两个 Python 包的依赖：

```bash
pip install -r py-agent/requirements.txt
pip install -r web/requirements.txt
```

## 第四步：安装 Web 前端

```bash
cd web-ui
npm install
cd ..
```

## 第五步：启动 Web 管理面板

```bash
uvicorn web.main:app --reload --host 0.0.0.0 --port 8000
```

## 第六步：登录管理面板

打开浏览器访问 [http://localhost:8000](http://localhost:8000)，使用 `.env` 中设置的 `WEB_PASSWORD` 登录。

在管理面板中可以查看 Agent 列表、对话记录、系统状态等。

## 第七步：启动 Rust 核心引擎

保持 Web 服务运行，新开一个终端：

```bash
cd src
cargo run
```

Rust 核心启动后将自动加载 Agent 配置、建立消息总线、并通过 WebSocket 与 Web 后端通信。

## 验证启动

看到以下日志说明启动成功：

```
[INFO] CocoCat core started
[INFO] Agent 客服-001 loaded
[INFO] Agent 编程-002 loaded
[INFO] WebSocket connected to management panel
```

现在你可以通过管理面板或 API 与 Agent 团队交互了。
