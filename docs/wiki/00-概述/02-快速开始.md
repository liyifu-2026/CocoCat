# 快速开始

> **受众：** 新用户  
> **前提：** Python 3.10+, pip  
> **目标：** 5 分钟跑起来

## 1. 克隆并安装

```bash
git clone https://github.com/liyifu-2026/CocoCat.git && cd CocoCat
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
```

## 2. 配置 API Key

```bash
cp .env.example .env
# 编辑 .env，填入 LLM API Key（如 DEEPSEEK_API_KEY）
```

或创建 `config/auth.json`：
```json
{"deepseek": "sk-xxx"}
```

## 3. 启动

```bash
python -m cococat --port 8000
```

## 4. 验证

```bash
# 健康检查
curl http://localhost:8000/api/health

# 发送第一条消息
curl -X POST http://localhost:8000/api/chat \
  -H "Content-Type: application/json" \
  -d '{"content": "你好，请介绍一下你自己"}'
```

## 5. 打开 Web 面板

```bash
cd web-ui && npm install && npm run dev
# 访问 http://localhost:5173
```
