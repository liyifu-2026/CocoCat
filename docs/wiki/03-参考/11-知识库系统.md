# 知识库系统

知识库（KB）为 agent 提供可检索的领域知识。位于 `kb/` 目录。

## 目录结构

```
kb/
├── sources/               # 原始文档(用户提供)
│   ├── manual.md
│   └── api-spec.yaml
├── wiki/                  # 生成的 Wiki 页面
│   ├── index.md           # 知识库索引
│   ├── log.md             # 变更日志
│   ├── manual.md          # 生成的页面(YAML frontmatter)
│   └── api-spec.md
├── mounted_kbs.json       # 场景挂载配置
└── search_index.json      # 搜索索引
```

## 摄取流程

定义于 `py-agent/ingest.py`：

**双阶段 LLM 管道**：

```
阶段一: 分析
┌──────────────────────────┐
│  LLM 分析源文件            │
│  → title, type, entities  │
│  → concepts, key_points   │
│  → tags, related          │
│  → 输出结构化 JSON         │
└──────────┬───────────────┘
           ↓
阶段二: 生成
┌──────────────────────────┐
│  LLM 根据分析结果生成       │
│  标准 Wiki 页面            │
│  (Markdown + YAML 头)     │
└──────────┬───────────────┘
           ↓
阶段三: 更新
┌──────────────────────────┐
│  更新 index.md            │
│  追加 log.md 日志          │
│  重建搜索索引              │
└──────────────────────────┘
```

YAML frontmatter 内容：

```yaml
---
title: API 规范
type: reference
tags: [api, backend, rest]
entities: [server, client]
concepts: [认证, 路由, 数据库]
key_points:
  - 所有 API 需 JWT 认证
  - 响应格式统一为 JSON
related: [manual.md]
created: 2025-01-15
updated: 2025-01-20
---
```

## 搜索机制

`search_kb` 工具的执行流程：

```
1. Token 化: 查询拆分为 token (jieba 中文分词)
2. 权重评分: TF/IDF 风格评分 + 标题加权(×3)
3. 图扩展: 通过 entities/concepts/related 字段
   找到关联页面并追加
4. 上下文预算: 按评分排序，累计 ≤ 4000 token
5. 返回: [{"title": ..., "content": ..., "score": ...}]
```

搜索结果作为参考信息注入 agent 的 system prompt。

## 场景挂载

`mounted_kbs.json`：

```json
{
  "scenes": {
    "default": {
      "knowledge_bases": ["manual", "api-spec"]
    },
    "customer-service": {
      "knowledge_bases": ["faq", "product-manual"]
    }
  }
}
```

每个场景可挂载不同知识库。agent 只感知到本场景已挂载的知识库内容。

## CLI

```bash
# 手动触发摄取
python -m py-agent.ingest --source kb/sources/manual.md

# 重建搜索索引
python -m py-agent.ingest --rebuild-index

# 查看挂载配置
cat kb/mounted_kbs.json
```
