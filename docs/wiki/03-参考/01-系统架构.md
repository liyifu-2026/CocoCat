# 系统架构

CocoCat 采用四层架构设计,自顶向下依次为 Web 面板、FastAPI 后端、Rust 核心、Python Agent 运行时。

```
┌─────────────────────────────────┐
│  React SPA (web-ui/)            │  用户界面层
│  REST API 调用 + WebSocket 推送  │
└──────────────┬──────────────────┘
               │  HTTP REST + WebSocket
┌──────────────▼──────────────────┐
│  FastAPI Backend (web/)         │  管理层
│  CRUD · 认证 · Webhook · 路由   │
│  one-shot agent 进程 (场景对话)  │
└──────────────┬──────────────────┘
               │  JSON-RPC stdin/stdout
               │  + 文件系统轮询
┌──────────────▼──────────────────┐
│  Rust Core (src/)                │  调度层
│  进程管理 · 健康检查 · 消息总线  │
│  dispatch 转发 · hire 处理      │
└──────────────┬──────────────────┘
               │  JSON-RPC stdin/stdout
┌──────────────▼──────────────────┐
│  Python Agent Runtime (py-agent/)│  执行层
│  ReAct 循环 · 工具 · 记忆 · KB  │
│  心跳 · 邮箱 · 聊天群组        │
└─────────────────────────────────┘
```

## 各层职责

### React SPA (web-ui/)

用户管理界面,通过 REST API 调用后端,WebSocket 接收实时推送。

### FastAPI Backend (web/)

**定位**: 管理入口 + 外部通道。

- 认证(登录、JWT 验证、API Key)
- Agent/Scene/Knowledge 的 CRUD
- 外部聊天通道(微信、飞书、Web API)
- **场景对话**: 收到用户消息后,直接 spawn 一个一次性 Python agent 进程处理并返回
- Hire 审批(列表、通过、拒绝)
- WebSocket 推送状态

### Rust Core (src/)

**定位**: 常驻守护进程,agent 生命周期管理 + 消息调度。

- 读取 `agents/config.toml`,spawn 所有 enabled agent 子进程
- 通过 JSON-RPC stdin/stdout 与每个 agent 通信
- 健康检查:每隔 15s 调用 `try_wait()` 检测是否存活,死则重启
- Dispatch queue 轮询:读取 `agents/dispatch_queue/*.json`,转发给目标 agent
- Hire 处理:读取 `agents/hire_requests/approved/*.json`,更新 config + spawn
- 消息总线:所有聊天消息写入 `chat/group.jsonl`,提供持久化和读取
- 控制台输入 `quit`/`exit` 停止

### Python Agent Runtime (py-agent/)

**定位**: 每个 agent 独立的执行引擎。

- JSON-RPC 服务端:从 stdin 读取请求,处理后写 stdout
- ReAct 循环:LLM 调用 → 工具执行 → 循环 → 返回结果
- 26 种工具:文件、系统、Agent 协作、记忆、知识库、Web、技能、LSP
- 心跳线程(300s 周期):检查邮箱、聊天群组、定时任务
- Dream 记忆整合:分析历史记录,合并到 MEMORY.md

## 层间通信

| 方向 | 协议 | 说明 |
|------|------|------|
| web-ui → web/ | HTTP REST | RESTful API, JWT 认证 |
| web/ → py-agent | subprocess | 场景对话时 spawn 一次性进程 |
| web/ → src/ | 文件系统 | Rust 定期轮询 dispatch_queue + hire_requests |
| src/ → py-agent | JSON-RPC 2.0 | stdin/stdout 单行 JSON 协议 |
| py-agent → src/ | 文件系统 | dispatch_task 写 dispatch_queue |
