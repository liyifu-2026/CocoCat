# 更新日志

## [Unreleased]

### Feat — 插件系统
- 新增 `plugin_manager.py`：插件发现、安装、卸载
- 新增 `plugin_hooks.py`：`HookRegistry`，支持 pre/post tool call 钩子
- 新增 `tool_registry.py`：`PluginTool` 基类支持动态工具加载

- 新增 `channels/telegram.py`：Bot API 长轮询，无额外依赖
- 新增 `channels/discord.py`：discord.py Bot，Gateway Intents

### Feat — MCP Server
- 新增 `mcp_server.py`：独立 MCP 服务器
- Stdio 模式（Claude Desktop） + HTTP SSE 模式（`--port 8080`）
- 暴露 6 个工具：read_file, write_file, exec_command, glob_search, grep_search, web_fetch

### Feat — Skill Hub 增强
- `check_skill_dependencies()`：检查二进制依赖、环境变量、平台要求
- `load_agent_skills()` 支持 progressive 模式：仅注入摘要而非全文
- `search_marketplace()`：本地注册表 + 文件系统搜索

### Feat — 协作 DAG 增强
- 协作关系 DAG 可视化页面（dagre 布局）
- 侧面板展示任务摘要和回复详情
- 每 5 秒自动轮询刷新

### Feat — P0 安全增强
- `FileLock`：跨平台文件锁，支持超时、上下文管理器
- `atomic_write`：写临时文件 + rename 原子替换
- `wrap_with_namespace`：Linux namespace 隔离（PID/IPC/Network）
- 所有 MCP 工具通过完整沙箱组件保护
- 消息总线并发写入保护（FileLock + 消息 ID + 游标追踪）

### Strengthen
- 系统健康检查 API (`GET /api/health`)
- LSP 连接池、技能版本管理+卸载、AgentRunner 缓存

### Fix
- 移除每日记忆注入，Dream 不再写 daily log，零上下文开销
