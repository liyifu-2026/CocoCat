# 第一次对话

本教程将引导你启动 CocoCat，并向一个 agent 团队下达第一个任务。

## 前置条件

- 已完成[开发环境搭建](../00-概述/03-开发环境搭建.md)
- Rust、Python、Node.js 已安装
- 配置文件 `agents/config.toml` 和 `.env` 已就绪

## 步骤

### 1. 启动 Rust 核心

```bash
cargo run
```

你会看到类似输出：

```
[INFO] 正在加载 agent 配置...
[INFO] 已加载 3 个 agent
[INFO] 启动 Alice (leader)...
[INFO] 启动 Bob (employee)...
[INFO] 启动 Charlie (employee)...
[INFO] 所有 agent 已就绪，健康检查通过
>
```

`>` 提示符表示 Rust 守护进程已就绪。

### 2. 查看 agent 状态

在 `>` 提示符下输入 `status`：

```
> status
Agent         Status    Role      Scene
─────────────────────────────────────────
alice         running   leader    default
bob           running   employee  default
charlie       running   employee  default
```

### 3. 打开聊天

在新终端中启动 FastAPI 后端：

```bash
cd web
uvicorn main:app --reload --port 8000
```

打开浏览器访问 `http://localhost:8000`，进入场景对话页面。

### 4. 下达任务

在聊天输入框发送消息：

```
请调查项目进度并输出报告
```

或者通过 Python 脚本发送：

```bash
python -c "
from py-agent.channel import send_to_scene
send_to_scene('default', '请调查项目进度并输出报告', 'user_001')
"
```

### 5. 观察执行过程

消息会经过以下路径：

```
你 → 场景路由器 → Alice (leader) 的邮箱
     ↓
Alice 分析任务 → 决定拆分子任务
     ↓
Alice 通过 dispatch_task 工具将子任务分配给 Bob 和 Charlie
     ↓
Bob 收到邮件 → 执行 → 回复
Charlie 收到邮件 → 执行 → 回复
     ↓
Alice 收集结果 → 整合报告
     ↓
回复发送到聊天群组
```

### 6. 在聊天中查看结果

打开聊天界面，你会看到：

```
Alice: 我整理了调查结果。Bob 确认了后端进度(80%)，
Charlie 确认了前端进度(60%)。总体项目进度约 70%。
详细报告已保存到 project_report.md
```

在 Rust 终端中也能看到消息日志：

```
[MSG] user_001 → Alice: 请调查项目进度并输出报告
[MSG] Alice → Bob: 调查后端进度
[MSG] Bob → Alice: 后端进度 80%
[MSG] Alice → Charlie: 调查前端进度
[MSG] Charlie → Alice: 前端进度 60%
[MSG] Alice → user_001: 总体进度约 70%
```

## 完成

你已成功完成第一次对话！Alice 作为 leader 自动协调了团队成员完成你的任务。
