# 场景系统重新设计

> 日期：2026-05-18  
> 状态：设计完成，待实现

## 1. 背景

当前场景系统存在三个问题：

1. **场景太静态** —— 场景配置以 YAML 文件形式存放在 `scenes/` 目录，改配置要手动编辑文件，缺少动态创建和管理能力
2. **场景 : Agent 关系不对** —— 当前场景通过 roster 管理多个 Agent，但实际使用中场景和 Agent 应该是 1:1 的绑定关系
3. **缺乏生命周期管理** —— 场景没有状态（草稿/运行/暂停/归档），无法追溯和管理

## 2. 核心决策

### 2.1 场景 : Agent = 1:1

一个场景绑定一个 Agent。场景是用户看到的「服务窗口」，Agent 是在背后干活的 AI。Agent 由系统在创建场景时自动生成，用户不需要手动管理 Agent 层的概念。

### 2.2 双层配置模型

**Agent 层**（底色，跨场景通用）：

| 字段 | 说明 |
|------|------|
| 名称 | Agent 的显示名，默认等于场景名 |
| 性格/语气 | 亲切友好 / 专业严谨 / 简洁高效 / 幽默风趣 |
| 语言偏好 | 中文 / English / 中英混合 |
| 头像 | 可选，默认生成 |

**场景层**（工作装，进入场景后套上）：

| 字段 | 说明 |
|------|------|
| 场景名称 | 用户可见的场景标识 |
| 场景用途 | 客服 / 内容写作 / 项目管理 / 数据分析 / 自定义 |
| 场景描述 | 一句话描述这个场景做什么 |
| 场景规则 | LLM 读取的场景说明书（自动生成 + 可编辑） |
| 挂载知识库 | 多选，可上传新 KB |
| 启用技能 | 多选，从已有技能列表勾选 |
| 可用工具 | 允许/禁用哪些工具（默认全开） |
| 渠道入口 | Web 聊天 / 微信 / 飞书 / API（可多选） |
| LLM 配置 | 模型 / temperature / 最大轮数（选填，用全局默认） |
| 可见性 | 私有 / 团队共享 |

**叠加逻辑：**
```
最终提示词 = 场景规则（主） + Agent 底色（辅，不违反场景规则）
```

场景规则是约束，Agent 底色是气质。Agent 可以有幽默感，但如果场景要求严肃专业，就不能开玩笑。

### 2.3 不引入模板（本期）

本期不实现模板市场和模板系统。用户从空白创建场景，通过向导步骤完成配置。模板作为未来迭代方向。

## 3. 场景生命周期

四态：

```
运行中 ←→ 已暂停
  ↓           ↓
已归档     已删除
  ↓           ↓
已删除     (30天后销毁)
```

| 当前状态 | 可转到的状态 | 说明 |
|----------|-------------|------|
| 运行中 | 暂停 / 归档 / 删除 | 正常响应消息，可编辑配置 |
| 已暂停 | 运行 / 归档 / 删除 | 停止响应，保留配置和数据 |
| 已归档 | 恢复运行 / 删除 | 只读，不能改配置，可复活或销毁 |
| 已删除 | 无（可恢复） | 软删除，30天内可恢复，超期永久销毁 |

## 4. 场景创建流程

五步向导：

1. **场景用途** —— 名称、用途类型、一句话描述
2. **Agent 风格** —— Agent 名称、说话风格、语言、AI 模型
3. **知识 & 技能** —— 挂载知识库、启用技能
4. **渠道入口** —— Web / 微信 / 飞书 / API
5. **确认创建** —— 回顾所有配置，确认后创建

创建完成后跳转到场景运行页：左边聊天界面，右边场景设置面板（随时可调配置）。

## 5. 场景管理

场景列表页：卡片式布局，每张卡片显示：
- 场景名称 + 状态标签（运行中 / 已暂停 / 已归档）
- 描述、Agent 名、KB、渠道的摘要
- 可操作按钮：进入聊天 / 编辑 / 暂停/恢复 / 归档 / 删除

已归档卡片降低透明度以示区别。
末尾常驻「+ 新建场景」卡片。

## 6. 与现有系统的关系

### 6.1 需要改动的部分

- **场景存储**：场景配置从 `scenes/{name}/*.yaml` 迁移到 SQLite
- **Agent Store**：支持动态创建 Agent（目前只支持从 YAML 加载 Residents）
- **Scene API**：新增创建/编辑/删除/暂停/归档/恢复等端点
- **前端**：新增场景向导、场景列表、场景运行页

### 6.2 保持不变的部分

- 场景上下文注入机制（CONTEXT.md → 系统提示词）
- 知识库挂载和搜索
- 技能加载系统
- 渠道入口绑定

### 6.3 待废弃的部分

- `scenes/*/roster.json` —— 场景 : Agent 变为 1:1，不再需要 roster
- 场景目录结构 `scenes/{name}/` —— 配置迁移到 DB

## 7. 不在本期范围

- 模板市场 / 模板系统
- 审批流程
- 场景版本管理
- 跨场景协作 / 场景间消息传递
- Batch 批量操作场景
