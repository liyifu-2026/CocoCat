# Chat DM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Auto-create per-agent DM groups and display them in Chat sidebar with status dots.

**Architecture:** Rust `init_default_group()` creates DM groups; `send_message` handler auto-dispatches to the DM's agent; frontend splits sidebar into Channels + DMs.

**Tech Stack:** Rust (rusqlite), React/TypeScript

### Task 1: Rust — Auto-create DM groups in init_default_group

**Files:**
- Modify: `src/db/chat_groups.rs` — `init_default_group()`

- [ ] **Step 1: Add DM group creation after general group**

In `init_default_group()`, after creating the "general" group and its admin member, and after populating agent members, add:

```rust
// Create DM groups for each agent
let mut agents = conn.prepare("SELECT id, name FROM agents WHERE status != 'stopped'")?;
let agent_rows: Vec<(String, String)> = agents
    .query_map([], |row| Ok((row.get::<_, String>(0)?, row.get::<_, String>(1)?)))?
    .filter_map(|r| r.ok())
    .collect();
drop(agents);

for (agent_id, agent_name) in &agent_rows {
    let dm_id = format!("dm_{}", agent_id);
    conn.execute(
        "INSERT OR IGNORE INTO chat_groups (id, name, announcement, is_default) VALUES (?1, ?2, '', 0)",
        rusqlite::params![dm_id, agent_name],
    )?;
    conn.execute(
        "INSERT OR IGNORE INTO chat_group_members (group_id, agent_id, name, role) VALUES (?1, 'admin', 'Admin', 'owner')",
        rusqlite::params![dm_id],
    )?;
    conn.execute(
        "INSERT OR IGNORE INTO chat_group_members (group_id, agent_id, name, role) VALUES (?1, ?2, ?3, 'member')",
        rusqlite::params![dm_id, agent_id, agent_name],
    )?;
}
```

```rust
// DM mode: if group_id starts with "dm_", dispatch to that agent directly
let target_agents: Vec<String> = if group_id.starts_with("dm_") {
    let agent_id = group_id.strip_prefix("dm_").unwrap_or("").to_string();
    if agent_id.is_empty() {
        return Ok(Json(serde_json::json!({"error": "invalid dm group"})));
    }
    vec![agent_id]
} else if mentions.is_empty() {
    group.members.iter()
        .filter(|m| m.agent_id != "admin")
        .map(|m| m.agent_id.clone())
        .take(1)
        .collect()
} else {
    mentions
};
```

```tsx
// Add Agent interface info
interface Agent {
  id: string
  name: string
  status: string
}

const { data: agentsData } = useQuery({ queryKey: ["agents"], queryFn: () => agentsApi.list() })
const agents: Agent[] = agentsData?.agents ?? agentsData ?? []

const agentStatus: Record<string, string> = {}
```

Replace the sidebar rendering:


Extract the group button into a helper component or keep inline:
```tsx
function GroupButton({ group, selectedGroup, onSelect, messagesData }: {
  group: any; selectedGroup: string | null; onSelect: (id: string) => void; messagesData: any
}) {
  const lastMsg = messagesData?.messages?.slice(-1)[0]
  return (
    <button key={group.id} onClick={() => onSelect(group.id)}
      className={`flex w-full items-center gap-3 px-4 py-3 text-left text-sm hover:bg-accent/50 transition-colors ${selectedGroup === group.id ? "bg-accent" : ""}`}>
      <div className="relative shrink-0">
        <div className={`flex h-10 w-10 items-center justify-center rounded-lg ${group.is_default ? "bg-primary/10 text-primary" : "bg-muted text-muted-foreground"}`}>
          <Hash className="size-5" />
        </div>
      </div>
      <div className="flex-1 min-w-0">
        <span className="font-medium truncate">{group.name}</span>
        {lastMsg && <div className="text-xs text-muted-foreground truncate mt-0.5">{lastMsg.recalled ? "[recalled]" : lastMsg.content}</div>}
      </div>
    </button>
  )
}
```
