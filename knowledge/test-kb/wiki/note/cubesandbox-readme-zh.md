# CubeSandbox 中文 README

## 概述

Cube Sandbox 是一款基于 RustVMM 与 KVM 构建的高性能、开箱即用的安全沙箱服务。它既支持单机部署，也能够很方便地扩展到多台机器的集群服务。同时对外兼容 E2B SDK，在 60ms 内就可以创建一个具备服务能力的硬件隔离沙箱环境，并保持着小于 5M 的内存开销。

## 核心优势

- **极致冷启动**：基于资源池化预置和快照克隆技术，端到端冷启动一个可服务的沙箱时间平均 < 60ms
- **单机千例的高密部署**：基于 CoW 技术实现极致内存复用，单实例内存开销低至 < 5MB，一台机器可跑数千个 Agent
- **真正的内核级隔离**：每个 Agent 拥有独立的 Guest OS 内核，杜绝容器逃逸
- **零成本迁移（E2B 完美平替）**：原生兼容 E2B SDK 接口规范，只需替换 URL 环境变量
- **网络安全**：基于 eBPF 的 CubeVS 实现内核态沙箱间网络隔离
- **开箱即用**：支持一键快速部署，单机/集群部署皆可
- **事件级快照回滚（coming soon）**：百毫秒级的高频快照回滚能力
- **可用于生产环境**：已在腾讯云生产环境中大规模验证

## 性能对比

| 维度 | Docker 容器 | 传统虚拟机 | CubeSandbox |
|---|---|---|---|
| 隔离级别 | 低（共享内核） | 高（独立内核） | **极高（独立内核 + eBPF）** |
| 启动速度 | 200ms | 秒级 | **< 60ms** |
| 内存开销 | 低 | 高 | **< 5MB** |
| 部署密度 | 高 | 低 | **单机数千实例** |
| E2B SDK 兼容 | / | / | **完全兼容** |

## 快速开始

需要一台支持 KVM 的 x86_64 Linux 环境（WSL 2 / Linux 物理机 / 云上裸金属 / 普通云服务器均可）。

### 四步启动

1. **准备运行环境**：克隆仓库并初始化
2. **启动 Cube 沙箱服务**：一键安装脚本
3. **制作代码解释器沙箱模板**：使用预构建镜像创建模板
4. **运行第一段 Agent 代码**：使用 E2B SDK 在沙箱中运行代码

## 架构组件

| 组件 | 职责 |
|---|---|
| **CubeAPI** | 兼容 E2B 的 REST API 网关（Rust） |
| **CubeMaster** | 编排调度器，负责资源调度与集群状态维护 |
| **CubeProxy** | 反向代理，将请求路由到对应沙箱 |
| **Cubelet** | 计算节点本地调度组件 |
| **CubeVS** | 基于 eBPF 的虚拟交换机，提供网络隔离 |
| **CubeHypervisor & CubeShim** | 虚拟化层 |
