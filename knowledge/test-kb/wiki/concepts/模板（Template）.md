# 模板 (Template)

在 [[CubeSandbox]] 的工作流中，**模板** 是一个预构建的、只读的沙箱镜像，它定义了沙箱启动时的初始状态。用户（[[控制器用户]]）通过创建和管理模板来定制所需的执行环境。

## 模板的作用

- **标准环境定义**：将特定语言、库、工具等依赖打包，例如“Python 3.11 + PyTorch + 代码解释器工具”模板。
- **快速克隆**：所有沙箱实例都是模板的写时复制副本，这使得 [[毫秒级冷启动]] 和 [[高密度部署]] 成为可能。
- **版本管理**：管理员可以创建不同的模板版本，满足不同任务或不同时间的环境需求。

## 操作命令

使用 `cubemastercli` 工具创建模板的典型命令：

```bash
cubemastercli tpl create-from-image <image-id> --name my-template
```

此过程从基础镜像启动一个临时 “构建器” 实例，安装指定软件，最后将其状态保存为只读模板。

## 最佳实践

- **最小化**：只安装任务必需的软件，以减小模板体型，降低内存共享失效的频率。
- **分层**：对于共享基础环境的多个项目，可以构建基础模板，再用增量模板叠加，但需注意 CubeSandbox 当前支持的模板模式。
- **安全更新**：定期更新模板的基础操作系统补丁，确保安全。
