# 高密度部署 (<5MB 开销)

**高密度部署** 是 [[CubeSandbox]] 实现低成本大规模运行的关键，其指标为每个沙箱实例自身占用的独立内存低于 5MB。

## 如何实现

- **写时复制（CoW）**：所有从同一 [[模板（Template）]] 克隆的沙箱实例共享模板的只读内存页。只有实例进行写操作时，才会分配自己独立的物理页。这使得数千个实例可以几乎共用一套操作系统和预装软件的内存。
- **Rust 语言裁剪**：[[RustVMM]] 本身是使用 Rust 编写的轻量级 VMM，避免了过去 QEMU 等重型 VMM 带来的巨大内存开销。
- **内核精简**：Guest OS 内核经过裁剪，移除了不必要的驱动和子系统，减少了基础内存足迹。

## 规模价值

“单机数千个 Agent” 意味着一个较低配置的云服务器即可支持成百上千个 AI Agent 的安全并发执行，大幅降低了基础设施成本。对于大规模 Agent 任务（如自动化测试并行的自动化环境），这种密度直接转化为经济可行性。
