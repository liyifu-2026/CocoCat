# CubeSandbox

**CubeSandbox** 是一个极速启动、高并发、安全且轻量化的 AI Agent 沙箱服务。它专为运行 AI 生成的不受信任代码而设计，通过结合 [[RustVMM]]/[[KVM]] 虚拟化技术，提供真正的 [[硬件级强隔离]]，同时实现 [[毫秒级冷启动]] 和 [[高密度部署]]。

## 核心特性

- **硬件级安全**：每个沙箱实例拥有独立的 Guest OS 内核，彻底杜绝容器逃逸风险。参考 [[硬件级强隔离]]。
- **极致性能**：冷启动时间低于 60 毫秒，满足 AI Agent 高频创建与销毁的需求。详见 [[毫秒级冷启动]]。
- **轻量低开销**：利用写时复制技术，每个沙箱实例仅需少于 5MB 的内存开销，单机可承载数千个并发实例。参考 [[高密度部署]]。
- **完全兼容 E2B**：接口层完全遵循 [[E2B SDK]] 规范，用户只需修改 API 地址和环境变量即可零成本迁移。参见 [[完全兼容 E2B]]。
- **eBPF 网络隔离**：通过 [[CubeVS (eBPF-based)]] 实现内核态网络策略，增强沙箱间的细粒度安全控制。参考 [[基于 eBPF 的网络隔离]]。
- **生产就绪**：项目已在[[腾讯云]]生产环境大规模运行，验证了可靠性与扩展性。

## 架构概览

CubeSandbox 的服务端架构包含以下核心层：

- **API Service**：接收用户请求，遵循 E2B 兼容的接口规范。
- **Sandbox Manager**：管理沙箱生命周期、资源池化和模板克隆。
- **虚拟化引擎**：基于 RustVMM 和 KVM 的轻量级虚拟机，实现硬件级隔离和快照启动。
- **网络隔离层**：通过 CubeVS（eBPF）在内核态实施网络策略。

## 目标场景

- AI Agent 代码执行（如自动化基准测试 SWE-Bench）
- 强化学习（RL）训练环境
- 代码解释器沙箱
- 需要安全隔离的任意代码运行平台
