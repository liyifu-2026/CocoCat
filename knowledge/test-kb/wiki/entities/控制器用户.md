# 控制器 / 用户

在 [[CubeSandbox]] 系统中，**控制器**或**用户**是指与沙箱服务交互的人类操作员或自动化流程。他们通过管理 API 或命令行工具（如 `cubemastercli`）执行以下关键任务：

- 创建和管理 [[模板（Template）]] ：使用 `cubemastercli tpl create-from-image` 等命令从基础镜像构建包含特定环境的沙箱模板。
- 启动和停止沙箱实例：基于模板创建沙箱，供 AI Agent 使用。
- 配置安全策略：定义 [[基于 eBPF 的网络隔离]] 规则，控制沙箱的网络行为。
- 监控和运维：查看沙箱状态、资源消耗和审计日志。

## 角色细分

在实际场景中，可分为：
- **系统管理员**：负责部署 CubeSandbox 服务、管理节点和底层 [[PVM (Prologue Virtual Machine)]]。
- **应用开发者/Agent 开发者**：使用 [[E2B SDK]] 或 API 编程式地创建沙箱，执行代码。

该角色是使用 [[CubeSandbox]] 服务的人类接口，所有指令最终通过控制器转化为对 [[RustVMM]]/[[KVM]] 和 [[CubeVS (eBPF-based)]] 的调用。
