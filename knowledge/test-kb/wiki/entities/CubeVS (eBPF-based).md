# CubeVS (eBPF-based)

**CubeVS** 是 [[CubeSandbox]] 内置的网络隔离组件，利用 eBPF（extended Berkeley Packet Filter）技术在内核中对进出沙箱的网络数据包进行过滤和策略控制。它是实现 [[基于 eBPF 的网络隔离]] 的核心实现。

## 工作原理

- 每个沙箱虚拟机启动后，CubeVS 会动态加载 eBPF 程序到宿主机的网络协议栈路径上。
- 这些 eBPF 程序根据预设的策略（如允许/禁止访问特定 IP、端口、协议或内部虚拟网络）在内核中直接处理数据包，无需将流量拉入用户态，性能极高。
- 策略由中心的 Sandbox Manager 下发，实现了对每个沙箱[[实例]]的独立网络访问控制。

## 安全价值

在 [[硬件级强隔离]] 的计算隔离基础上，CubeVS 提供了关键的网络安全层：

- 防止恶意代码从沙箱内探测或攻击宿主机或其他沙箱的网络。
- 阻止数据泄露通道，如禁止沙箱访问外部网络，但允许访问内部 API 服务。
- 提供审计和监控能力，记录异常网络行为。
