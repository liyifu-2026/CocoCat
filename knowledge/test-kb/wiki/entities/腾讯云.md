# 腾讯云

**腾讯云** 是 [[CubeSandbox]] 项目的发起者和主要贡献者。该项目源于腾讯云内部对安全、高性能 AI Agent 沙箱的需求，并在其生产环境中经历了大规模的服务验证。

## 贡献与验证

- **大规模运行**：CubeSandbox 已在腾讯云的多个 AI 和自动化服务中承载真实负载，服务了数百个业务线，证明了其宣称的 [[高密度部署]]（单机数千沙箱）和 [[毫秒级冷启动]] 可在严苛的生产条件下稳定保持。
- **开源贡献**：腾讯云将 CubeSandbox 开源，遵循 Apache 2.0 许可证，回馈社区，并接受外部贡献。
- **技术背书**：腾讯云的生产实践为 CubeSandbox 的安全模型（[[硬件级强隔离]]、[[基于 eBPF 的网络隔离]]）和性能基准提供了权威背书。
