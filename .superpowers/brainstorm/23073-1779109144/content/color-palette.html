配色方案

一笔猫 + 什么色调？

A

墨 + 紫光 — 东方赛博

主：深黑/浓墨色（#0d0d0d 或 #1a1a2e）
辅：单一紫色荧光（#7c3aed 或更暗的靛紫）
很像一款日本暗黑系工具。墨线猫 + 紫光节点。背景全黑或极深灰。

B

墨 + 留白 — 纯东方极简

主：纯黑墨线（#111）
背景：白/米白/宣纸色（#fafaf7 或类似）
没有多余颜色，全靠线条和留白。像无印良品 + Zaha Hadid 的交叉。

C

墨 + 青绿 — 宋瓷釉色

主：深墨色线
辅：青瓷/汝窑那种灰绿色（#6b9080 或 celadon tone）
东方但不老气，温润如玉。适合浅色背景。
