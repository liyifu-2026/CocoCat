Agent 头像风格

一笔猫做 Logo 很明确。但 18 个 agent 角色头像怎么做？

A

纯色几何抽象 —— 每个角色一个抽象符号

不用猫，也不用人。每个 agent 角色对应一个极简几何符号：代码Agent→菱形◇、写作→竖线丨、数据→圆点阵列、客服→两个同心圆。18个抽象符号，统一用墨线+留白风格。

B

一笔猫变体 × 18 —— 同一只猫的不同「态」

同一只一笔猫，通过微调线条角度、耳朵倾斜、眼神方向区分角色。像日本「禅画」里的圆相——同一个圆，画者的心境不同，圆也不同。细看有差，粗看统一。

C

先不要 Agent 头像 —— 目前用不到，以后再说

当前 19 个 SVG 头像是死代码。现在先专注 Logo + og-image + Hero。agent 头像等将来真正需要时再按统一风格补充。
