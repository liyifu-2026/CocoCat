协作可视化的四个设计层级（由浅入深）

L1

聊天内联

Agent 发言中嵌入工具调用卡片、DAG 阶段卡片。所有信息在聊天流里自然呈现——用户不需要切到别的地方看。

L2

侧边面板

右侧常驻面板展示 DAG 拓扑图（节点+连线）、Agent 实时状态、任务队列。聊天和监控并行。

L3

全屏 DAG 工作台

独立的 DAG 全景视图（可缩放节点图），类似 CI/CD Pipeline 可视化。用于复杂任务的整体把控。

L4

时间线回放

任务完成后的时间线回放——展示 Agent 如何协作、谁在什么时候做了什么决策。用于复盘和学习。

这四个层级应该是共存关系。问题是：你希望哪个作为默认视图？哪个作为可展开的深度视图？

A

默认 L1 + 可展开 L2/L3

平常聊天流里看一切，需要详情时打开侧面板或进入全屏 DAG 视图

B

默认 L2 + 收起到 L1

右侧面板默认展开显示 DAG 图，聊天区聚焦对话。简单任务时面板可折叠，退化为 L1 内联卡片

C

根据任务复杂度自适应

简单对话 → L1。触发 DAG 后 → 自动展开 L2 侧面板。用户可手动进入 L3 全屏工作台。L4 是历史回放入口。
