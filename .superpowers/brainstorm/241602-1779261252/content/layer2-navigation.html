但 CocoCat 不是聊天工具，是协作平台
Discord 式侧栏适合以服务器/频道为组织单元的产品。但 CocoCat 中 Scene 只是组织维度之一——还有 Agent 管理、知识库、全局设置等。
SceneRail 承载了太多不同性质的东西：场景切换 + Chat 入口 + Settings 入口 + 功能导航，语义混乱。

导航层的三个关键设计选择

点击选择你倾向的方案

A

保留 SceneRail，增加顶部导航

SceneRail 只做场景切换（纯 Scene），顶部 tab bar 承载 Chat / Dashboard / Agents / Knowledge 等功能切换。类似 Notion + Discord 混合。

Pros

  • 改动量小
  • Scene 概念集中

Cons

  • 两层导航增加认知
  • SceneRail 利用率低
B

统一侧边栏，替代 SceneRail

一个可折叠的侧边栏，顶部是 Scene 列表，下方是固定功能区（Agents / Knowledge / Settings）。类似 Linear / Vercel 风格。

Pros

  • 单一导航入口
  • 层级清晰

Cons

  • 改动量大
  • Scene 和功能平级可能不够突出
C

Dashboard 为中心的辐射式

Dashboard 重做为真正的首页（系统状态 + 最近活动 + 快速入口），所有功能从 Dashboard 辐射出去。SceneRail 保留但降级为「场景收藏」。

Pros

  • 给新用户明确起点
  • Dashboard 终于有内容

Cons

  • Dashboard 设计难度高
  • 可能多一层跳转
