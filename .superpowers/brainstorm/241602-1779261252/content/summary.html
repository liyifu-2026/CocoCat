交互重构 · 设计方向总结

五层递进分析后的整体设计决策

已确认的设计决策一览

L1
初体验 · 冷启动
基调：安静中带着温度。品牌亮相（猫+Taiji S曲线）+ 能力展示 + Suggestion Chips。首次用户不迷失。
新增：Welcome 页面 / Onboarding 流程
L2
空间感知 · 导航架构
Dashboard 为辐射中心（系统状态 + 最近活动 + 快速入口）。SceneRail 降级为场景收藏。功能通过 Dashboard 分发。
重做：Dashboard（从空白页→全局中枢）/ SceneRail 定位调整
L3
核心交互 · 对话体验
优先级排序：① 工具调用可视化（有生命感的思维过程展示）② 上下文面板+DAG 进度 ③ 富内容渲染（Mermaid/代码/文件预览）④ 流式质感打磨 ⑤ 输入增强（/命令、@提及）⑥ Agent 身份区分
重做：Chat 消息组件体系 / 上下文信息面板
L4
管理体验 · Agent/Scene/KB
创作工作室隐喻。画布式组织（拖拽关系、可视化连接）。Agent=角色、Scene=画板。AI 辅助创建（自然语言→自动填充表单→人工微调）。
重做：Agent 创建流程 / Scene 详情页 / 关系可视化
L5
高级工作流 · DAG 编排
四个层级共存：L1 聊天内联卡片 → L2 侧边面板拓扑图 → L3 全屏 DAG 工作台 → L4 时间线回放。根据任务复杂度自适应展开。
新增：DAG 节点图组件 / 全屏工作台 / 时间线回放

整体交互模型：从「功能集合」到「叙事流」

用户旅程：冷启动 → 探索 → 深度使用
