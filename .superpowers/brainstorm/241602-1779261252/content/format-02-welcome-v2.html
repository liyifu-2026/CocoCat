#2 Welcome · 三个更有意思的方向

Welcome 不该是一张说明书——用户不是来读文档的

方向 A：直接开聊

不要介绍页，Welcome 本身就是第一次对话。猫猫直接问你「今天想做什么？」

Welcome = Chat 的零状态。没有功能卡片，只有一句问候和一个输入框。
🐱
你好，我是 CocoCat
我有一整个 AI 团队可以帮你。
告诉我想做什么，我来安排。
📝 写周报
🔍 分析代码
🌐 调研
💡 随便聊聊
或者直接告诉我想做什么...
优点：消除「阅读→理解→操作」的认知跳转。Welcome 就是产品的第一口体验。
风险：如果用户不知道该说什么，输入框的沉默会带来焦虑。需要足够多且好的 suggestion chips。

方向 B：猫猫醒来

Welcome 是一段品牌微动画。猫从蜷缩到舒展，工作室亮起来。动画结束自然过渡到输入态。

3秒品牌动画 → 渐变为方向A的对话态
🐱
伸个懒腰...
↓ 动画结束，猫眨眨眼，「今天想做什么？」出现在输入框里 ↓
优点：品牌记忆深刻。猫的「醒来」= CocoCat 就绪的隐喻。安静中带着温度。
风险：3秒动画对回访用户是干扰。需判断：首次 → 完整动画；回访 → 跳过动画直接对话态。

方向 C：你的工作室

Welcome 展示一个空的工作室空间——Agent 工位、知识书架、任务板。暗示「这里将要充满你的团队」。

俯视工作室的插画感布局，空位等待填充
📋 任务板 等待第一个任务
🪑 Agent
🪑 Agent
🪑 Agent
📚 知识库 空空的书架
你的 AI 工作室已就绪
创建第一个 Agent，或者直接说你想做什么
优点：空间隐喻贯穿始终（和创作工作室一致）。空位的「期待感」推动用户行动。和 Dashboard 的语言统一。
风险：静态插画感可能需要实际插图才能生效。纯 CSS 较难达到预期效果。

三个方向的本质差异

A 直接开聊 B 猫猫醒来 C 你的工作室
核心动作打字观看浏览
Welcome→Chat距离零（本身就是Chat）近（动画结束即Chat）远（需点击进入）
开发量低中（动画）高（插画+布局）
