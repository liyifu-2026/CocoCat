#2 Welcome · 前端格式文档

首次登录后的品牌亮相页——建立认知、给出方向

1. 概述

页面目的：首次用户登录后（或未完成引导的回访用户）展示的品牌页面。告诉用户 CocoCat 是什么、能做什么、怎么开始。
用户场景：管理员初始化后第一次进入 / 新用户第一次登录 / 老用户清除了 localStorage
所属层级：L1 初体验
关键约束：页面必须有一个显式的「跳过」入口——老用户或不想看的人可以直接进 Dashboard

2. 路由与导航

路由：/welcome
进入条件：localStorage 无 onboarding_complete 标记 且已登录
可跳转：「开始」→ /onboarding  |  「跳过」→ /dashboard
后续：完成 Onboarding 后标记已读，不再显示

4. 组件树

WelcomePage
├── BrandSection ← Logo + 标题 + 一句话定位
│ ├── CatLogo（圆形太极构图）
│ ├── WelcomeTitle（Display XL, Zen Antique）
│ └── WelcomeSubtitle
├── CapabilityCards ← 3张能力卡片
│ ├── CapabilityCard（icon + 标题 + 描述）
│ └── ...
├── ActionSection ← CTA 按钮 + Suggestion Chips
│ ├── PrimaryCTA（开始按钮）
│ ├── SuggestionChips（快速入口）
│ └── SkipLink（跳过）
└── BackgroundAtmosphere ← warm-glow + grain 叠加

5. 状态设计

Loading 态：无异步加载（纯静态页面），不需要。
Empty 态：不适用——此页面本身就是「空态」的替代。
Error 态：不适用——纯展示页。
Edge cases：用户点 Suggestion Chip「帮我写周报」→ 如果没有 Agent 还需要先走 Onboarding 创建。需要判断：有 Agent → 直接进 Chat 带预设 prompt；无 Agent → 提示先创建。

6. 数据流

无 API 调用：此页面为纯展示。
localStorage：点击「开始」→ 跳转 /onboarding。点击「跳过」→ 设置 onboarding_complete = true，跳转 /dashboard。
预检查：Suggestion Chips 点击时，需检查 Agents 是否为空（GET /api/agents），决定下一步。

7. 交互细节

入场动画：Logo + 标题 fadeSlideUp stagger-1。能力卡片 stagger-2,3,4。CTA stagger-5。时长约 1.5s 可感知全貌。
猫的微交互：Logo 中的猫缓慢呼吸式微缩放（scale 1 → 1.03 → 1，3s loop）。鼠标 hover 猫时猫眼跟随光标。
能力卡片：hover 微上浮 + 阴影加深。点击无反应（仅展示）。
Suggestion Chips：hover 边框变为主色，点击触发对应流程。
键盘：Enter → 等同于点击主 CTA。Escape → 等同于点击跳过。
