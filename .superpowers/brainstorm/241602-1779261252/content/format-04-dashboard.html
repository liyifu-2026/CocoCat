#4 Dashboard · 前端格式文档

工作室总览——整个产品的核心枢纽，Studio 范式的具象化

1. 概述

页面目的：一屏看清团队状态。Coco 调度台 + Agent 工位 + 资料架 + 当前任务流。
用户场景：日常进入的第一页。看一眼谁在忙、谁空闲、有什么新任务、资料架有什么更新。
所属层级：L2 空间感知
关键原则：工位排列是个人视图（每个人可以自己拖拽调整），Agent 数据是共享的。默认布局由系统自动生成。

2. 路由与导航

路由：/dashboard（默认首页，替代 /chat）
进入：登录后 / Onboarding 完成后
可跳转：点击 Agent 工位 → 查看详情（弹出面板，不跳页）/ 点击 Coco 调度台 → 进入 Chat / 点击资料架 → /knowledge
SceneRail：切换 Scene 时 Dashboard 刷新为该 Scene 的 Agent 列表

4. 关键设计决策：固定角色 vs 用户创建

✅ 固定角色（始终存在，不可删除）：
· Coco（Main AI）— 调度台，所有 Scene 中都有。橘猫 Logo。
· kb-agent（知识库管理员）— 有 Scene 就有 kb-agent，负责文件处理和知识库运维。
✅ 用户创建的 Agent：
· 在工位区自由排列（个人视图，拖拽调整）
· 新 Agent 自动出现在工位区空位
· 可删除、可编辑
✅ 空态处理：
· 新建 Scene：Coco 调度台 + kb-agent 工位 + 空资料架 + 空工位区（虚线占位）
· 用户还没创建 Agent → 工位区显示「+ 添加第一个 Agent」引导卡片

5. 交互细节

拖拽：Agent 工位可在工位区内拖拽重排。使用 @dnd-kit。位置存 localStorage（个人偏好）。
点击 Agent 工位：右侧滑出详情面板（Agent 信息 + 当前任务 + 最近活动）。不跳页。
点击 Coco 调度台：进入 Chat（/chat?scene=当前Scene）。
任务流可视化：Coco 调度台 → 工作流连线 → Agent 工位（仅当有活跃 DAG 时显示虚线箭头动画）。
实时更新：Agent 状态轮询（5s）+ WebSocket 事件推送。工位边框颜色和状态指示实时变化。
