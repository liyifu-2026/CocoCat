Dashboard数据看板（卡片堆砌）「基地总览」——俯视平面图。Agent 工位 + 调度中心 + 知识仓库 + 休息区。猫在基地里走动。

DAGChat 内的进度条「生产链」——任务在工位之间流转的连线动画。从调度中心 → Dev工位 → Tester工位，可以看到「工作」在传递。
Memory无前端页面「经验仓库」——团队积累的记忆/事实，以「档案柜」的形式展示。
Profile个人设置「我的办公室」——个人空间。头像、偏好、API Key、活动记录。
猫的角色装饰性 Logo「基建副手」——在基地中走动。停在忙碌工位旁查看。叼着完成报告跑向你。偶尔在休息区打盹。是基地的「灵魂」。

这个方向的影响——需要你确认

1. 「创作工作室」概念被「基地」吸收 — 之前我们讨论的 Studio 画布（拖拽组织Agent/Scene/KB），现在变成基地俯视图本身。不需要独立 Studio 页面。
2. Scene 的概念转换 — Scene 不再是「上下文配置」，而是「基地的楼层」。切换 Scene = 切换楼层，看到不同的 Agent 和任务。
3. 猫从装饰变主角 — 猫不再「低调」。它是基建副手，有行为、有存在感、有功能（报告状态、提醒事项）。这和你最初选的「低调」有冲突——需要重新确认猫的存在感级别。
4. 页面清单变化 — Studio 可能不需要了（被基地吸收）。DAGWorkbench 变成基地内切换的「生产链视图」。TimelineReplay 变成「工作日志」。
5. 视觉风格的张力 — 「安静中带着温度」+「基地」可以共存：暖纸色调 + 俯视平面图 + 柔光。不是冷硬的工业风，而是温暖的、手工感的基地。
