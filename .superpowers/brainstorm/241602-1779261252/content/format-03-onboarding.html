#3 Onboarding · 前端格式文档

2-3 步引导：从空工作室到第一个 Agent 就位

1. 概述

页面目的：帮助新用户快速理解工作室概念并创建第一个 Agent。不是填表，是「布置工作室」。
用户场景：Welcome 点击「添加第一个 Agent」进入。老用户可通过 Dashboard 入口重新访问。
核心原则：每一步都可跳过。总时长控制在 2 分钟内。AI 辅助而非手动填表。
所属层级：L1 初体验

2. 路由与导航

路由：/onboarding
进入：Welcome → 点击 CTA / Dashboard 空态 → 点击引导入口
完成后跳转：工作室总览 (Dashboard)，新 Agent 已在工位上
localStorage：完成后设 onboarding_complete = true，Welcome 不再显示

5. 数据流

Step 1：暂存工作室名称到本地 state，不调 API（后续创建 Scene 时用）
Step 2：POST /api/agents（AI 填充的 Agent 配置）。同时需要解析自然语言的 API（如果后端暂无，可前端做简单的关键词→配置映射）
Step 3：设置 localStorage onboarding_complete = true，跳转 /dashboard

6. 交互细节

步骤切换：淡入淡出过渡（非滑动，保持聚焦）。StepIndicator 圆点填充动画。
AI 填充动效：用户输入描述后 1s 延迟 → AutoFillPreview 从 Coco 调度台的位置「生长」出来（暗示 Coco 在帮你配置）。
全程可跳过：每个 Step 都有跳过按钮。Step 3 跳过 = 直接进 Dashboard（空工作室，无 Agent）。
Step 3 迷你工作室：新 Agent 的工位有一个微小的「亮灯」动画——虚线变实线 + 绿色光晕扩散。
