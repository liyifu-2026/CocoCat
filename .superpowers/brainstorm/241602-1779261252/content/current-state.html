现有优势

  • 视觉风格统一、暖色调氛围好
  • SceneRail 类似 Discord，结构清晰
  • Chat 流式输出、Mermaid 渲染等交互细节到位
  • CSS 动画克制优雅（fadeSlideUp、messageIn）
  • shadcn/ui 组件体系成熟

明显痛点

  • 无 Onboarding / 新手引导流程
  • Dashboard 是空白占位页
  • 空状态设计缺失（chat 空、agents 空、scenes 空）
  • Settings 模态框过大，信息架构扁平
  • Scene → Agent → Knowledge 三者的跳转关系不直观
  • DAG 任务流的进度可视化薄弱
  • 缺少全局搜索 / 命令面板（cmdk 已安装但未充分使用）
