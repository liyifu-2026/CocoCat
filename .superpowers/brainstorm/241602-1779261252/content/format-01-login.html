5. 状态设计

Loading 态
登录按钮 → spinner + "正在登录..."
初始检查 → 页面居中 spinner + "正在检查系统状态..."
Error 态
卡片上方滑入错误提示（shake 动画）
区分：凭证错误 / 网络错误 / 系统未初始化

6. 数据流

API：
· GET /api/auth/status → 判断是否需要初始化
· POST /api/auth/init → 首次管理员注册（admin setup）
· POST /api/auth/login → 登录获取 JWT
状态管理：useAuth context → 存储 token + 用户信息
无 WebSocket：登录页不需要 WS 连接

7. 交互细节

入场动画：LoginCard 从下往上 fadeSlideUp（stagger-2, 0.12s 延迟）+ 背景光晕渐显
密码可见切换：点击眼睛图标切换 input type="password" ↔ "text"
错误动画：卡片微 shake（translateX ±4px）+ 红色边框闪烁
键盘：Enter 提交，Tab 切换字段，Escape 清除错误提示
记住我：localStorage 持久化 token（勾选时），否则 sessionStorage
