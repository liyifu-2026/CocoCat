新增模块
  • KBService — 纯函数服务层，把散布在 ingest/*.py 的能力统一封装
  • kb-agent — 注册在 agent 系统的专用 agent
  • 6 个 agent 工具 — 薄封装 KBService
  • Cron 调度 — 生成周期性维护任务
  • 前端上传/对话面板
不改动的模块
  • TaskWorker 只扩展 kb-task dispatch，不改核心循环
  • IngestPipeline 保持不变，KBService 调用它
  • knowledge.py routes 保持不变
  • knowledge/ 目录结构不变
  • Frontend Knowledge.tsx 扩展而非重写
