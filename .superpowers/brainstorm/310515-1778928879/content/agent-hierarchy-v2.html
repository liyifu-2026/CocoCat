Agent 分层：修正版

常驻 agent 平级，分工不同；Worker 是临时执行池

🏠
Resident Agent · 常驻角色
地位 平级，无主从关系，各自独立负责一个领域
生命周期 系统启动时创建，常驻不销毁
工具 各自拥有领域专属工具集
UI 入口 各自有专属对话页
绑定 1:1 深度绑定到各自的页面/场景
后台能力 可自主运行后台任务（cron/事件）
🏊
Worker Pool · 临时执行池
地位 被 Resident agent 调用
生命周期 触发即创建，完成即销毁
工具 通用执行工具（bash/file/browser...）
UI 入口 无，对用户不可见
绑定 不绑定，池子复用
