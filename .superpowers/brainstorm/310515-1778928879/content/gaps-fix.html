设计缺口 & 修正

缺口 1：其他 agent 没有只读 search_kb 工具

目前其他 agent 只能通过 system prompt 里的 KB overview 感知 KB 存在。不能主动检索 wiki 页面内容。需要给所有普通 agent 加一个 search_kb 工具，权限设为只读。

缺口 2：kb-agent 缺少 ingestion skill 和专属对话界面

当前 kb-agent 只是一个后台 subagent。没有前端对话面板让用户在 KB 页面直接跟它交互。也缺少 knowledge-ingestion skill 来指导它如何拆解材料。

修正后的完整设定

┌───────────────────────────────────────────────────────┐
│  kb-agent（知识库管理员）                         │
│  位置：KB 详情页 → 专属对话面板                         │
│  权限：读 + 写（创建/修改 wiki 页面、触发维护操作）       │
│  Skill：knowledge-ingestion（指导拆解材料）           │
│  Tools：                                              │
│    ┌─────────────────────────────────────────────┐     │
│    │ search_kb     — 搜索 wiki（读写均可）        │     │
│    │ write_wiki    — 创建/更新 wiki 页面          │     │
│    │ run_dedup     — 运行去重管线                 │     │
│    │ run_lint      — 运行健康检查                 │     │
│    │ gen_overview  — 生成/更新 KB 全局概览        │     │
│    │ cascade_del   — 级联删除源文件及相关页面      │     │
│    │ get_graph     — 获取知识图谱 + 洞察          │     │
│    └─────────────────────────────────────────────┘     │
└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│  普通 agent（其他场景的 agent）                    │
│  权限：只读                                           │
│  Tools：                                              │
│    ┌─────────────────────────────────────────────┐     │
│    │ search_kb     — 搜索 wiki（只读）            │     │
│    │ read_wiki     — 读取指定 wiki 页面           │     │
│    └─────────────────────────────────────────────┘     │
│  注：这两个工具在 kb-agent 上也可以调用，但 kb-agent    │
│  额外拥有写权限的工具                                   │
└───────────────────────────────────────────────────────┘
kb-agent 的工作流（收到材料后）
  1. 加载 knowledge-ingestion skill
  2. 调用 ingest（两阶段 LLM 管线）
  3. 写入 wiki 页面（FILE blocks → entities/concepts）
  4. 更新 index.md + log.md
  5. 可选：触发 dedup、生成 overview
kb-agent 的日常维护
  1. 定期 lint 检查 → 报告孤儿页面/断链
  2. 定期 dedup → 合并重复页面
  3. 定期 overview → 重新生成全局概览
  4. 源文件删除 → 触发级联清理
