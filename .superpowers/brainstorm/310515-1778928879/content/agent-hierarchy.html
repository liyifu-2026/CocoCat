Agent 分级体系设计

从 MAIN/SUB 二元 → 三级分层，支持系统级专属 agent

🎯
Orchestrator
编排者
Coco
角色：不亲自干活
工具：DAG 编排 + 分发
绑定场景：否
对话入口：主聊天页
  • 定义 DAG 工作流
  • 分派任务给各级 agent
  • 汇总结果返回用户
🔧
Service Agent
专属服务者
kb-agent（当前）
未来：review-agent 等
角色：管理某个系统领域
工具：领域专属工具集
绑定场景：否（全局）
对话入口：专属管理页
  • 拥有领域专属 skill
  • 自主后台维护（cron）
  • 用户可直接对话
  • Worker agent 也可调用它
👷
Worker Agent
执行者
现有 sub-agent
角色：在场景中执行任务
工具：全工具集 + 只读 KB
绑定场景：是
对话入口：Coco 分发
  • 绑定到具体业务场景
  • 通过 Coco 分派任务
  • 可调用 Service agent
  • 可只读查询 KB
AgentRole 枚举改为：

class AgentRole(Enum):
    ORCHESTRATOR = "orchestrator"   # Coco，只有一个
    SERVICE      = "service"        # 系统级专属 agent
    WORKER       = "worker"         # 场景绑定的执行 agent

关键区别：
┌─────────────┬──────────┬──────────┬──────────┐
│             │ Coco     │ kb-agent │ Worker   │
├─────────────┼──────────┼──────────┼──────────┤
│ 绑定场景     │ ✗        │ ✗        │ ✓        │
│ 专属对话页   │ ✓（主聊） │ ✓（KB页） │ ✗        │
│ 全工具       │ ✗（编排） │ ✗（KB）   │ ✓        │
│ 专属工具     │ DAG      │ KB 8工具  │ ✗        │
│ 被 Coco 调用 │ —        │ ✓        │ ✓        │
│ 后台自主运行 │ ✗        │ ✓ (cron)  │ ✗        │
└─────────────┴──────────┴──────────┴──────────┘
