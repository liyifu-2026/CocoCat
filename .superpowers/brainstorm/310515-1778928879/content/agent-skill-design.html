knowledge-ingestion skill

指导 kb-agent 如何拆解材料、注入 KB 的 skill 文件

# skills/public/knowledge-ingestion.md

## 材料分析
- 识别材料类型（文档/代码/对话/图片）
- 提取关键实体和概念
- 判断与现有 wiki 的重叠度

## 注入策略
- 新实体 → 创建 entities/ 页面
- 新概念 → 创建 concepts/ 页面
- 已有页面补充 → merge 而非覆盖
- 使用 wikilink `[[slug]]` 建立关联

## 质量控制
- 检查 frontmatter 完整性
- 去重检查（dedup-not-duplicates）
- 更新 index.md 和 log.md
触发机制
事件驱动（即时响应）
  • 用户上传源文件 → Worker 创建 kb:ingest 任务 → dispatch 给 kb-agent
  • 用户在前端对话窗发指令 → 直接路由给 kb-agent
  • 用户删除源文件 → Worker 创建 kb:cascade 任务
定时巡检（cron 驱动）
  • kb:lint — 每天一次，检查健康
  • kb:dedup — 每周一次，合并重复
  • kb:overview — 每周一次，刷新概览
  • 实现方式：cron 生成 pending task 写入 tasks 表，Worker 认领后 dispatch 给 kb-agent
Cron 实现 — 不引入外部 cron 库。在 Worker 主循环中加一个简单检查：

# worker.py — 每次轮询时检查是否需要生成维护任务
def maybe_enqueue_maintenance():
    for kb_name in list_kb_dirs():
        if due('lint', kb_name, interval='24h'):
            enqueue_task(kb_name, 'kb:lint')
        if due('dedup', kb_name, interval='7d'):
            enqueue_task(kb_name, 'kb:dedup')
