设计 Section 2：Agent 工具设计

kb-agent 8 个工具，普通 agent 2 个只读工具

kb-agent 专属（读写）
search_kb搜索 wiki 页面，返回标题+摘要
read_wiki读取指定页面完整内容
write_wiki创建/覆盖 wiki 页面
run_dedup运行去重管线 → 合并重复页面
run_lint健康检查：孤儿页面+断链+缺 frontmatter
gen_overview生成/更新 KB 全局概览
cascade_del级联删除源文件+关联 wiki 页面
get_graph获取知识图谱+洞察（连接/缺口/桥梁）
普通 agent（只读）
search_kb搜索 wiki 页面（只读）
read_wiki读取指定页面完整内容（只读）

search_kb 和 read_wiki 在两个 agent 类型上都是同一个工具实现，区别在于 kb-agent 还可以调用 write_wiki。

工具实现方式
每个工具都是 KBService 方法的薄封装，不包含业务逻辑：

# 示例：search_kb 工具
async def search_kb(kb_name: str, query: str) → list[SearchResult]:
    return kb_service.search(kb_name, query)

# 工具注册时标注权限
tools = {
    "search_kb": Tool(fn=search_kb, read_only=True),
    "write_wiki": Tool(fn=write_wiki, read_only=False),
    ...
}
