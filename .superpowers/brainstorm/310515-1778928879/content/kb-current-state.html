CocoCat KB — Current State Overview

What exists, what's wired, what's disconnected

Wired & Working
  • File upload → ingest pipeline
  • KB overview in agent system prompt
  • Wiki page browser (frontend)
  • Substring search (API only)
  • Knowledge graph (D3.js)
  • SHA256 ingest caching
Code Exists, Not Wired
  • 3-stage Dedup pipeline
  • Overview generation
  • Cascade source deletion
  • Image pipeline (PDF/DOCX)
  • Lint health checks
  • Knowledge graph insights
Spec'd But Not Built
  • Agent-side search_kb tool
  • Frontend upload UI dialog
  • WebSocket progress events
  • knowledge-ingestion skill file
Integration Gap
  • Agents can't search KBs
  • No agent tool to write to KBs
  • KB maintenance not autonomous
  • No scheduled health workflows
Key insight: The KB has a solid ingestion + storage core, but agents
can only read KB files via overview prompts. They can't search, can't write,
and can't trigger maintenance workflows (dedup, lint, overview).
The KB is a passive file store, not an active agent knowledge system.
